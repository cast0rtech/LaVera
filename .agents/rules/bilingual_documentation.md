# Bilingual Documentation Rule (English & Spanish)

## Guideline
All documentation in this repository must always be maintained bilingually in both **English** and **Spanish**:
1. **Root README:**
   - `README.md` (English)
   - `README.es.md` (Spanish)
   - Both must contain language selectors at the top (`[English](README.md) | [Español](README.es.md)`).
2. **Guides:**
   - `GUIDE.md` (English)
   - `GUIA.md` (Spanish)
   - Both must link to each other at the top.
3. **Submodule / Component Documentation:**
   - Any subfolder README must have both `README.md` (English) and `README.es.md` (Spanish).
4. Whenever creating or updating documentation, always update both English and Spanish versions simultaneously to keep them synchronized.
