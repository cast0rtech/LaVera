Importador de Datos de Tesla (Tessie & TeslaFi)

Procesamiento 100% Local

Sube directamente tus exportaciones descargadas desde Tessie (archivos .json o .csv) o TeslaFi (archivos drives.csv, charges.csv, idles.csv, o calendar.csv). El motor de LaVera detectará automáticamente el formato, normalizará unidades (millas/km, °F/°C, Wh/mi) y almacenará los datos de forma persistente.

☁️

Arrastra tus archivos de Tessie o TeslaFi aquí

O haz clic para seleccionar archivos CSV o JSON desde tu dispositivo

💡 ¿Cómo obtener tus archivos de exportación?

  • Tessie: Abre la app o web de Tessie → Ajustes → Exportar Datos → Descarga el historial en formato CSV o JSON.
  • TeslaFi: Entra en TeslaFi.com → Menú Drives, Charges o Battery Report → Haz clic en Export to CSV.

⚡ Conexión Online con Tessie Cloud API

Desconectado
Sincronización Automática

Conecta LaVera Hub directamente con los servidores de Tessie utilizando tu Personal Access Token. Esto permite descargar automáticamente tus viajes, sesiones de carga, curva de salud de batería y telemetría en vivo sin necesidad de exportar archivos manualmente.

¿Cómo conseguirlo? Inicia sesión en dash.tessie.com/settings/api o en la app de Tessie (Ajustes > Desarrollador / API > Generate Token).
